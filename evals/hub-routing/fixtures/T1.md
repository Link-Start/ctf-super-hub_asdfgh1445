## 1. 当前判断

这是一道纯密码学 RSA 题：只给 n、e、c 三个数，题面自述 "Standard RSA, nothing fancy"，考点几乎可以确定是「n 的素数因子存在某种弱点，先分解 n，再按标准 RSA 流程解密拿 flag」。

## 2. 为什么走这条路

- 输入形态完全匹配：无附件、无远程服务，只有 n / e / c 三个整数，这正是 RSA 数论题的最小输入。
- ctf-crypto 的 description 明确点名 RSA，且其知识库里直接覆盖本题所需：RSA 基础流程（`phi = (p-1)*(q-1)`，`d = inverse(e, phi)`，`m = pow(c, d, n)`）、各类因式分解攻击（Fermat、Pollard p-1、多素数、受限数字素数等），还提供 RsaCtfTool 自动化套件。
- 阶段匹配：当前卡在「分类已明、直接进入利用」阶段，ctf-crypto 正是产出 flag 的交付 skill；`solve-challenge` 只做首轮分类，对本题只会重复同一个判断，属冗余。
- 无边界冲突：ctf-crypto 的转向条件（需要逆向二进制、流量取证、Web 交互）本题都不涉及。

## 3. 先做这三步（交给 `/ctf-crypto` 执行）

1. **给 n 做体检**：算出 n 的比特长度，用 `sympy.factorint` / 试除法查小因子，顺带确认 e 与 phi 是否互素。
2. **小因子无果就跑自动化**：`RsaCtfTool.py -n <n> -e <e> --uncipher <c>`，它会依次尝试 Wiener、Fermat（p、q 相近）、Pollard p-1 等标准分解攻击。
3. **分解成功后标准解密**：由 p、q 算 phi 和私钥 d，`m = pow(c, d, n)`，把 m 转成字节串即可读出 flag。

## 4. 每步在干什么

- 第 1 步是在判断 n 的「弱点类型」——Easy 难度的 RSA 题通常意味着 n 能被某种常规手段分解，而不是暴力破解。
- 第 2 步是把这个「弱点猜测」外包给自动化工具，几分钟内扫完常见攻击面，省得逐个手写。
- 第 3 步是 RSA 的教科书式收尾：拿到因子后私钥可直接算出，解密只剩一次模幂运算。

## 5. 没结果怎么办

- 若 n 是标准强度的难以分解的大数（1024+ bit、无特殊结构），回到 ctf-crypto 的 rsa-attacks 清单核对特殊条件：本题 e=65537 排除小指数开方；只有一组密文排除共模与 Hastad 广播；没有 oracle 排除 LSB / Bleichenbacher 类攻击——若全部排除，回头检查题面是否还藏了材料（隐藏附件、出题方页面的额外线索），必要时用 `ctf-misc` / `ctf-osint` 补情报。
- 若后续真出现需要逆向的附件或服务交互，再由 ctf-crypto 的转向规则切到 `ctf-reverse` / `ctf-web`，不用现在预判。

## 6. 术语速查

- **n（模数）**：两个大素数 p、q 的乘积，RSA 的安全性就建立在「从 n 反推 p、q 很难」上。
- **e（公钥指数）**：加密用的指数，这里 65537 是最常见的安全默认值。
- **c（密文）**：`c = m^e mod n`，m 是藏着 flag 的明文整数。
- **分解（因式分解）**：把 n 拆回 p × q，是解开本题的钥匙。
- **phi / d**：phi = (p-1)(q-1) 是欧拉函数；d 是 e 关于 phi 的模逆元，即私钥。
